# Página Pessoal

**Uma página pessoal estática construída com HTML5 para praticar estruturação semântica, conteúdo e navegação básica na web.**

[Ver demonstração](https://pratesddev.github.io/fe_pagina_pessoal/)

---

## 📖 Sobre

O projeto foi desenvolvido como exercício introdutório de desenvolvimento web. Ele organiza informações de apresentação, interesses, objetivos e contato em uma página pessoal construída com HTML5.

A página utiliza elementos semânticos, títulos hierarquizados, listas, imagem com texto alternativo e links de telefone, e-mail e LinkedIn. Os dados exibidos são exemplos fictícios: antes de publicar uma versão pessoal, substitua nome, textos, avatar e contatos pelo conteúdo real.

---

## ✨ Funcionalidades

- [x] Estrutura HTML semântica com cabeçalho, conteúdo principal, seções e rodapé.
- [x] Apresentação pessoal com imagem ilustrada.
- [x] Seções de apresentação, informações gerais, interesses e objetivos.
- [x] Lista de contatos com links `tel:`, `mailto:` e LinkedIn.
- [x] Textos alternativos na imagem principal.

## 🚀 Começando

### Pré-requisitos

- Navegador moderno.
- Git opcional, caso queira clonar o repositório.

### Executando

Abra diretamente o arquivo `index.html` no navegador.

Para clonar o projeto:

```bash
git clone https://github.com/pratesddev/fe_pagina_pessoal.git
cd fe_pagina_pessoal
```

Depois, abra `index.html` no navegador ou a pasta no Visual Studio Code. Como se trata de uma página estática, não há dependências para instalar nem servidor de aplicação para iniciar.

---

## 💻 Uso

Personalize o conteúdo diretamente em `index.html`:

1. Substitua `Fulano de Tal`, os textos fictícios e o rodapé.
2. Troque os dados de telefone, e-mail e LinkedIn pelos contatos reais.
3. Substitua ou mantenha a imagem em `assets/avatar-1.png`, ajustando o atributo `alt`.
4. Atualize o título da página e o conteúdo das seções conforme necessário.
